Critical · Blockers
Critical01CORS & CSRF hardcoded to localhostImmediate
src/payload.config.ts:46–47
Why it matters
Only localhost + a LAN IP are allowed. On the real domain, admin login and every authenticated API call fail on CSRF rejection.
Fix
Drive both from an env var, e.g. cors: [SITE_URL]; include localhost only outside production.
Critical02Placeholder phone baked into SEO metadataImmediate
src/app/(frontend)/contact/page.tsx:19 · src/seed/index.ts:53
Why it matters
The contact page hardcodes (864) 266-5347 into search snippets. The brief flags phone as pending — a wrong number ships to Google and duplicates the Settings source of truth.
Fix
Confirm the real number, then build the meta description from Settings rather than a literal.
Critical03No production image host whitelistedBefore launch · verify
next.config.ts:15–21
Why it matters
Only a local media path is allowed. If production photos are served from any other origin (CDN / object storage), every truck image throws a runtime error.
Fix
Confirm the deploy's media strategy and add the production host to images.remotePatterns.
High Priority
High04Safety Orange fails AA as text on lightBefore launch
Design token · src/app/(frontend)/styles.css:11 · pervasive
Why it matters
Measured #F26B0F on bone = 2.75:1 (needs 4.5:1). Affects section labels, inline links, hover states across nearly every page.
Fix
Add a darker "orange-ink" (~#B4530A) for small text on light; keep bright orange for large display + on-dark. (Applied in this report.)
High05Hero downloads 160 frames (6.2 MB) on loadBefore launch
src/components/home/Hero.tsx:153–156
Why it matters
160 image requests fire on mount, competing with LCP and hammering mobile connections and the bandwidth budget.
Fix
Load progressively — frame 0, then a coarse subset, then backfill; or throttle concurrency to ~6; or cut to ~90 frames.
High06No error boundaries anywhereBefore launch
Missing error.tsx / global-error.tsx
Why it matters
Any server-render error shows users the raw Next.js crash screen instead of a branded fallback.
Fix
Add a branded error.tsx (retry) plus a root global-error.tsx.
High07No social-share images (OpenGraph / Twitter)Before launch
Site-wide · truck detail especially
Why it matters
Sharing any link — especially a truck — shows a bare card with no photo. A real conversion loss for a visual product.
Fix
Static OG image site-wide + dynamic per-truck image from its primary photo; add twitter: summary_large_image.
High08Public forms have no spam protectionBefore launch
src/collections/Leads.ts · FleetInquiries.ts
Why it matters
Open create with only per-process IP rate-limiting won't stop bot spam polluting the lead inbox this business runs on.
Fix
Add a hidden honeypot + minimum time-to-submit check. Free, no third party.
High09Public API can inject internal lead fieldsBefore launch
src/collections/Leads.ts:108–129
Why it matters
Open create with no field-level access lets a crafted request set status, internalNotes, timestamps — corrupting the sales pipeline.
Fix

Credit where due

Built Right — Don't Touch

The foundations are strong and shouldn't be revisited. This is well above typical agency work.

Access control & RBAC

Employees edit only their own drafts; role changes are admin-only; the draft → review → publish workflow is thorough and correct.

Clean client/server split

Deliberate separation keeps server imports out of the client bundle — a common leak, avoided here.

Sensitive data handled well

The financing form deliberately never collects SSN or bank details — only a name and contact. Exactly right.

SEO scaffolding

Per-page canonicals, templated titles, a resilient sitemap, robots, and Product / AutoDealer JSON-LD from one source.

Reduced-motion support

Respected both in global CSS and in the hero's JavaScript path — rare and thoughtful.

Secrets hygiene

.env gitignored, large source media excluded, a documented .env.example. Nothing sensitive committed.

Methodology. Full read of the codebase (~9,000 lines) applying SEO, accessibility (WCAG 2.2 AA), React / Next.js, and writing rubrics. Contrast ratios were computed, not estimated.
